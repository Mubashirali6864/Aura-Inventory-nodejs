----------------------------------------------------------------------
1. MODULE PURPOSE
----------------------------------------------------------------------
The Reports module provides executive performance intelligence, total net
sales revenue calculations, sales return deductions, Gross Margin / Profit
analytics, Average Order Value (AOV) computation, category sales contribution
breakdowns, 6-month historical monthly trends, and multi-branch sales auditing.

----------------------------------------------------------------------
2. FEATURES FOUND
----------------------------------------------------------------------
- Top KPI Summary Cards:
  - Net Revenue (PKR, adjusted for returns).
  - Total Orders Count (excluding non-binding quotes and returns).
  - Average Order Value (AOV = Net Revenue / Total Orders).
  - Estimated Gross Profit (PKR, computed from line-item sale vs. purchase prices).
- Six-Month Monthly Trend Visual Chart (Revenue vs Profit per month).
- Category Sales Contribution Donut Breakdown (Top categories by sales volume).
- Month-over-Month (MoM) Growth percentage tracker.
- Store branch filtering (`All`, `Shop 1`, `Shop 2`).
- Date period filtering (`All Time`, `Today`, `This Week`, `This Month`).
- Live search filtering by customer name or invoice number.
- Safe division guards preventing `NaN` or `Infinity` when orders count = 0.

----------------------------------------------------------------------
3. ACTUAL WORKFLOW
----------------------------------------------------------------------
1. Data Fetching:
   Component mounts -> Executes parallel API calls `GET /api/sales` and `GET /api/products`.
2. Metric Computation:
   - Filters out non-binding Quotation records from revenue and profit aggregations.
   - Adjusts each sale line item: adds revenue for `Sale`, subtracts revenue for `Return`.
   - Computes margin for each line item: `(salePrice - costPrice) * quantity`.
   - Groups sales by category and month.
3. Visualization:
   Displays KPIs, monthly bar/line charts, category distribution, and detailed
   tabular breakdown.

7. DATABASE FIELDS INVOLVED

----------------------------------------------------------------------
9. CREATE / UPDATE / DELETE OPERATIONS
----------------------------------------------------------------------

----------------------------------------------------------------------
10. BUSINESS LOGIC
----------------------------------------------------------------------
- Quotation Isolation: Non-binding quotes must NEVER inflate sales figures.
  Verified that quotations are properly excluded from confirmed revenue.
- Return Inversion: Returns reduce total revenue and gross profit by the exact
  refunded amount and cost basis.
- Zero-Division Protection: If order count is 0, AOV returns 0 rather than `NaN`.

----------------------------------------------------------------------
11. CALCULATIONS
----------------------------------------------------------------------
- Net Revenue:
  $$\text{Net Revenue} = \sum_{\text{Sales}} \text{Sale.total} - \sum_{\text{Returns}} \text{Return.total}$$
- Gross Profit / Margin:
  $$\text{Gross Profit} = \sum (\text{Sale Items Profit}) - \sum (\text{Return Items Profit})$$
  $$\text{where } \text{Line Profit} = (\text{Sale Price} - \text{Cost Price}) \times \text{Quantity}$$
- Average Order Value:
  $$\text{AOV} = \frac{\text{Net Revenue}}{\text{Confirmed Orders Count}}$$
